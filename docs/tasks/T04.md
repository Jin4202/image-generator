## 구현 순서

1. scene references/승인 버전 scope를 검증한다.
2. create/get/CAS update/deep-copy duplicate 구현.
3. client-only Konva pen/eraser/labeled boxes와 PNG 업로드 연결점을 구현.
4. normalized layout과 참조의 저장/reload 테스트를 추가한다.

## 인수 기준

CAS 충돌409; duplicate는 다른 ID와 독립 content; 정규화 box 경계/미승인 참조 차단.

현재 acceptance suite는 최소 실행 명세다. 위 기준의 미포함 정상/실패/경계 case를 추가하여 완료해야 한다. 기존 테스트를 삭제/약화하거나 반환형을 바꾸지 않는다.
