# T18 — 사용자 문구 자산 → 에셋

선행: T14/T16/T17. 상태: 계획.

## 소유 파일
src/app/projects/page.tsx, src/app/scenes/page.tsx, src/app/_studio/ui.tsx, src/app/page.tsx, src/app/_studio/generation.tsx, src/app/assets/page.tsx. 신규 tests/e2e-acceptance/T18.wording.spec.ts. 기존 browser 테스트의 해당 문구 locator/기대값과 README 제품 안내 문구 수정 허용.

## 필수 계약/참조
T10 UI 계약. 사용자에게 보이는 명칭만 ‘에셋’으로 통일한다. Asset/assets 식별자·DB·URL/API 계약은 그대로 유지한다.

## 구현 순서
1. 메뉴, 페이지 제목, 버튼, 빈 상태, 도움말, 승인/버전 안내, 접근성 label에서 ‘자산’을 찾아 ‘에셋’으로 바꾼다.
2. ‘자산 준비’→‘에셋 준비’ 등 동일한 행동을 유지하고 테스트 locator를 갱신한다.
3. 현재 제품 사용 안내도 맞춘다. 원본 기획과 과거 완료 기록은 역사적 자료이므로 일괄 치환하지 않는다.

## 인수 기준
/assets와 프로젝트/장면/생성 화면의 사용자 문구에 ‘자산’ 없음; ‘에셋’ 표시; 메뉴 링크와 승인·선택 흐름 정상. API /api/assets, DB assets, Asset 타입, 저장된 사용자 입력 내용은 변경되지 않음.

## 검증 명령
npm run test:e2e:acceptance -- T18.wording.spec.ts
rg -n '자산' src/app src/components
rg 결과는 사용자 문구가 0건이면 성공(exit 1이 정상). 공통 완료 gate는 follow-up-plan.md 참조.

## 범위 밖
타입/라우트/DB 이름 변경, 사용자 저장 데이터 치환, 전체 번역 시스템 도입.
