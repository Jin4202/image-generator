## 구현 순서

1. DB open 시 migration 존재/FK/WAL/busy_timeout 검증; Entities→table mapper를 작성한다. body schema와 indexed columns를 함께 검증/기록한다.
2. get/list detached object, insert, CAS replace 및 append-only 규칙을 구현한다.
3. BEGIN IMMEDIATE transaction과 Promise/nested callback 거부, rollback을 구현한다.
4. worker lease acquire/renew/release를 조건부 SQL로 구현한다.

## 인수 기준

재오픈 시 동일 record; stale CAS/불변 변경 거부; rollback에 잔여 변경 없음; 두 connection이 lease를 동시에 소유하지 못함.

현재 acceptance suite는 최소 실행 명세다. 위 기준의 미포함 정상/실패/경계 case를 추가하여 완료해야 한다. 기존 테스트를 삭제/약화하거나 반환형을 바꾸지 않는다.
