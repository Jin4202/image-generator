## 구현 순서

1. 공식 endpoint schema를 다시 확인하고 문서 날짜/차이를 기록한다.
2. buildFalInput exact mapping과 optional seed omission 구현.
3. 주입 transport/default instance client, upload/submit once/status/result를 구현.
4. safe result shape/HTTPS+DNS/redirect/timeout/stream cap 검증.
5. SDK 자동 submit retry 비활성화를 테스트로 증명한다.

## 인수 기준

두 endpoint의 mock transport payload 정확; 키/URLs public snapshot에 없음; 잘못된 결과/지원 필드 거부; 기본 테스트에서 실제 network0.

현재 acceptance suite는 최소 실행 명세다. 위 기준의 미포함 정상/실패/경계 case를 추가하여 완료해야 한다. 기존 테스트를 삭제/약화하거나 반환형을 바꾸지 않는다.
