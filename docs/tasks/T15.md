# T15 — manifest 참조 무결성 검사

선행: T02/T09/T12. 우선순위 P2.

## 소유 파일
src/application/services/effects.ts, tests/acceptance/T15.cases.test.ts(신규).

## 필수 계약/참조
contracts.md의 effects/Manifest v1, T09. 현재 base와 overlay 외의 workspace media 파일이 없어도 export가 성공한다.

## 구현 순서
1. export 직전 workspace snapshot을 고정하고 manifest가 열거할 모든 media의 blob을 읽는다. 같은 path는 중복 읽기 생략 가능하되 각 metadata는 확인한다.
2. 실제 byte 수/SHA-256과 media metadata를 비교한다. 이미지 decode 검증도 수행하고 저장 MIME/크기와 일치하는지 검사한다. 파일 I/O는 DB transaction 밖에서 수행한다.
3. 누락/손상/불일치는 STORAGE로 정규화하여 export 중단. 원래 경로나 raw 오류 노출 금지. 모든 검증을 마친 뒤 기존 합성·blob write·CAS/DB commit 수행.
4. 실패 시 새 ExportRecord/PNG Media가 일부만 commit되지 않도록 검사. 이미 쓴 orphan blob 허용 정책은 유지.

## 인수 기준
base/overlay가 아닌 media 누락도 STORAGE; 같은 길이 byte 변조는 hash 검사 실패; byte 수·MIME·차원 불일치 실패; 정상 snapshot은 기존 manifest 형태 유지; 실패 시 DB 신규 export/media 0개; 원본 불변.

## 검증 명령
npm run test:acceptance -- tests/acceptance/T15.cases.test.ts
npm run test:acceptance -- tests/acceptance/T09
공통 완료 gate는 follow-up-plan.md 참조.

## 범위 밖
zip/import, 완전한 이동식 백업, 자동 파일 복구, orphan GC. 읽기 검증 이후 외부 프로그램이 파일을 삭제하는 것까지 원자적으로 보장하지 않는다.
