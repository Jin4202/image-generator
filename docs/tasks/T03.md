## 구현 순서

1. project 생성/목록/workspace 조회를 구현한다.
2. style/asset version allocation을 transaction 안에서 수행한다.
3. media scope와 slot/reference 중복 검사, 승인 idempotency/불변성 구현.
4. workspace DTO를 allowlist schema로 반환하고 stable sort를 보장한다.

## 인수 기준

title trim; v1 승인 후 v2 생성 시 v1 불변; 승인 재요청 동일 결과; 다른 project 참조 거부.

현재 acceptance suite는 최소 실행 명세다. 위 기준의 미포함 정상/실패/경계 case를 추가하여 완료해야 한다. 기존 테스트를 삭제/약화하거나 반환형을 바꾸지 않는다.
