## 구현 순서

1. snapshot 승인 버전/media를 resolve하고 deep copy.
2. 고정 prompt assembly/reference sorting/capability warnings 구현.
3. canonical JSON hash와 15분 expiry로 preview 저장.
4. baseline/reference/mask/overflow/negative text 및 input mutation 부재 테스트.

## 인수 기준

같은 입력 동일 hash/compiled; refs 초과/미지원 mask 차단; text baseline의 refs 제외가 표시됨; parent 참조 맨 앞.

현재 acceptance suite는 최소 실행 명세다. 위 기준의 미포함 정상/실패/경계 case를 추가하여 완료해야 한다. 기존 테스트를 삭제/약화하거나 반환형을 바꾸지 않는다.
