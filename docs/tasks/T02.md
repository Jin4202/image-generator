## 구현 순서

1. blob path validation/realpath confinement/atomic content-addressed write를 구현한다.
2. sharp 실제 decode, MIME/size/pixels/pages 검사 후 원본 bytes 저장과 Media insert.
3. bounded multipart parser 및 raw media HTTP를 연결한다.
4. 같은 파일 재업로드, missing file, symlink, 잘린 이미지, limit 경계를 테스트한다.

## 인수 기준

유효 이미지 re-read bytes 동일; malformed/위장/초과/탈출 거부; project 없는 upload는 blob 생성 전 실패.

현재 acceptance suite는 최소 실행 명세다. 위 기준의 미포함 정상/실패/경계 case를 추가하여 완료해야 한다. 기존 테스트를 삭제/약화하거나 반환형을 바꾸지 않는다.
